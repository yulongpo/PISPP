# 信号智能处理平台

基于 Axure RP 导出的静态交互原型，面向窄带与宽带信号的数据构建、智能识别模型研发和效能评测。原型展示了从数据资产管理、信号生成与标注，到训练、模型管理和离线评测的完整流程。

## 产品定位

信号智能处理平台聚焦信号智能研发闭环，帮助用户高效构建信号数据资产、训练识别模型并验证模型效能。

当前原型不涵盖实时信号接入、在线推理、模型部署、告警运营或边缘协同等能力。

## 快速预览

本项目不需要安装依赖或执行构建命令。

1. 在浏览器中打开 `start.html`。
2. 原型默认进入“工作台”，可通过左侧页面导航访问其他功能页面。

也可以使用任意静态文件服务器将仓库根目录作为站点根目录后访问 `start.html`。

## 功能页面

- 数据资产管理：数据源管理、样本集管理、新建样本集及详情页面。
- 信号数据构建：窄带信号生成、宽带信号生成、模版中心和数据标注。
- 智能模型研发：训练任务、新建训练任务、新建实验任务、训练详情、模型管理和脚本管理。
- 模型评测：模型评测、新建评测任务和评测详情。
- 系统设置：系统设置页面。

## 目录说明

| 路径 | 说明 |
| --- | --- |
| `start.html` | Axure 原型预览入口。 |
| `*.html` | 各功能页面的静态原型文件。 |
| `data/` | 全局原型数据与样式。 |
| `files/` | 各页面对应的数据与样式资源。 |
| `images/` | 各页面使用的图片资源。 |
| `resources/` | Axure 运行时资源与第三方脚本。 |
| `plugins/` | Axure 原型插件资源。 |

## 维护说明

本仓库仅包含导出的静态原型。后续调整页面或交互时，请先在 Axure 源文件中更新并重新导出，再同步保留页面 HTML、`files/`、`images/`、`data/`、`resources/` 和 `plugins/` 中相互引用的资源，避免预览时出现样式、图片或交互资源缺失。
