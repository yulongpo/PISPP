# PISPP V2 已知边界与未解决问题

## 原型边界

- 当前所有场景数据、检测、预标注、提取、训练和评测均为 mock；数字用于演示业务关系，不代表真实算法性能。
- 没有真实 Raw IQ 读写、STFT、检测/分割/跟踪、DDC、滤波、重采样和 GPU 训练后端。
- 没有后端 API、对象存储、任务队列、用户权限、版本并发控制和持久化数据库；刷新页面会恢复内置 mock 初始状态。
- 模型格式标签用于展示研发资产形态，不表示已完成 PyTorch/ONNX/TensorRT 部署。

## 交互边界

- 时频画布拖动和随机化会修改当前浏览器会话内的 mock state，但不会写出 IQ 文件。
- 标注页面目前以表格输入完成类别和 known/unknown 修正；更复杂的鼠标框选、顶点编辑和多片段轨迹编辑留待真实标注工具接入。
- V2 使用 hash 路由，直接打开入口可预览；若浏览器限制本地文件脚本，使用静态 HTTP 服务器预览。

## 后续优先级

优先补齐 Scene/Annotation/Dataset 的服务端不可变版本、真实 TF 坐标校验和检测推理；随后接入真实 DDC 提取、训练队列、模型评测流水线和权限审计。
