# ADR-001：采用独立 V2 原型而不是直接重写 Axure 导出 HTML

## 状态

Accepted

## 背景

当前仓库主要是 Axure RP 导出的静态 HTML、JS 和资源。此类文件内部 ID、脚本和页面结构高度生成化，不适合作为长期人工维护源码。

本轮宽带重构涉及领域对象、信息架构、导航和大量交互重做，直接修改 Axure 导出代码风险过高。

## 决策

1. 保留 V1。
2. 新建 `prototype_v2/`。
3. 用可维护的 HTML/CSS/JS 实现宽带重构页面。
4. V2 视觉尽可能复用 V1 风格，但不复用 Axure 内部生成结构。
5. 完成后通过入口页同时提供 V1/V2 访问。

## 后果

优点：

- 不破坏现有成果；
- Codex 可维护；
- 容易迭代；
- 后续可转 React/Vue/Qt 原型。

代价：

- V1/V2 短期并存；
- 部分通用页面可能需要重新实现壳层。
