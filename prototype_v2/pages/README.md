# V2 页面路由

V2 使用一个无构建依赖的 SPA 入口，以下路由均由 `index.html` 内的统一导航渲染，不产生孤立页面或 404：

| 路由 | 页面 |
|---|---|
| `#/` | 工作台 |
| `#/data-sources` | 数据源管理 |
| `#/sample-sets` | 样本集管理 |
| `#/dataset` | Detection Dataset |
| `#/scene-builder` | 宽带场景生成 |
| `#/scene-detail` | 宽带场景详情 |
| `#/annotation` | 宽带时频标注 |
| `#/extraction` | 信号提取 |
| `#/narrowband` | 窄带信号详情 |
| `#/training` | 训练任务 |
| `#/experiment` | 实验详情 |
| `#/models` | 模型管理 |
| `#/evaluation` | 宽带检测评测 |
