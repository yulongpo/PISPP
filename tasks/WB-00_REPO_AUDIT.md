# WB-00 仓库与原型审计

## 目标

建立 V1 页面、导航、Axure 资源与宽带复制问题的事实基线。

## 执行

1. 枚举所有根级 HTML 页面。
2. 建立页面名称→业务模块映射。
3. 比较 `窄带信号生成.html` 与 `宽带信号生成.html` 的字段和控件。
4. 检查数据源、样本集、标注、训练、模型、评测中与宽带有关的字段。
5. 标记：
   - 直接复制；
   - 语义不明确；
   - 窄带专用但误用于宽带；
   - 缺失的宽带对象。
6. 不修改业务代码。

## 产出

- `docs/V1_AUDIT_REPORT.md`
- `docs/V1_PAGE_MAP.md`

## 验收

报告必须列出至少：
- 宽带场景生成问题；
- 场景/实例属性混淆；
- 宽带标注问题；
- 宽带训练/模型问题；
- 宽带评测问题；
- 宽窄带联动缺失。
